## CLI-022 — Validate minimum SDK artifacts and public compatibility

**Owner:** `CheatEngineNet/CheatEngine.Client` · **Kind:** validation · **Priority:** P1 · **Milestone:** CLI-M6

**Initial status:** Needs refinement. **Runtime validation:** Not executed by this bootstrap.

### Context and evidence

Client publishes a compatible SDK range, but source availability, package content and behavioral support are not equivalent.

**Evidence classification:** InheritedAuditBasis + Proposal; revalidate the pinned call path before implementation.

### Outcome and rationale
